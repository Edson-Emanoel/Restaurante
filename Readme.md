## Recursos Incríveis

- Animações suaves ao rolar a página com **ScrollReveal.js**
- Footer com onda SVG personalizada (efeito ondulado lindo!)
- Totalmente responsivo (mobile-first)
- Código limpo, comentado e sem dependências pesadas
- Carregamento extremamente rápido

## Tecnologias Utilizadas

- HTML5 semântico
- CSS3 com Flexbox + Grid + animações personalizadas
- JavaScript vanilla (ES6+)
- ScrollReveal.js → efeitos de entrada ao scroll
- SVG Wave Generator → footer ondulado
